# Writing with AI / Escribir con IA

## EN

### Best Models for Writing
- **Qwen2.5-Coder 7B** — Technical documentation, user manuals, guides
- **Qwen2.5-VL 7B** — Image descriptions, visual documentation
- **Llama 3.2 3B** — Quick drafts, outlines

### Prompts for Documentation
- "Write a user manual for [software name] including installation, configuration, and troubleshooting"
- "Create a README.md for a Python project that..."
- "Write a step-by-step guide for deploying with Docker"
- "Generate API documentation for this code: [paste code]"

### Writing in Spanish
All models support Spanish natively. Examples:
- "Escribe un manual de usuario para [nombre del software]"
- "Crea una guía de instalación paso a paso"
- "Redacta una presentación sobre [tema]"

### Tips
- Use 128K context for long documents
- Ask the model to create an outline first, then expand each section
- For bilingual docs, generate in English first, then ask for Spanish translation
- Save outputs as Markdown for easy formatting

## ES

### Mejores Modelos para Escribir
- **Qwen2.5-Coder 7B** — Documentación técnica, manuales de usuario, guías
- **Qwen2.5-VL 7B** — Descripciones de imágenes, documentación visual
- **Llama 3.2 3B** — Borradores rápidos, esquemas

### Prompts para Documentación
- "Escribe un manual de usuario para [nombre del software] incluyendo instalación, configuración y solución de problemas"
- "Crea un README.md para un proyecto Python que..."
- "Escribe una guía paso a paso para desplegar con Docker"
- "Genera documentación de API para este código: [pegar código]"

### Consejos
- Usa los 128K de contexto para documentos largos
- Pide al modelo que cree un esquema primero, luego expande cada sección
- Para docs bilingües, genera en español primero
- Guarda los resultados como Markdown para formatearlos fácilmente
